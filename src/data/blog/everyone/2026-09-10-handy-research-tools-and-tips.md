## Some free tools for research...

Everyone uses different tools, but here are some that I have found useful.

[Zotero](http://zotero.org) is probably your best choice for storing academic and research papers, keeping metadata tidy, citation, generating reference lists etc. It integrates well with word processors, and with sites such as JSTOR. Pretty much essential. ⭐️⭐️⭐️⭐️⭐️ Mac / Windows / Linux

[Obsidian](https://obsidian.md/) is a great note-taking tool, which uses Markdown to format text. Largely free if you don't want the bells and whistles, and everything stays on your own laptop, so it's good for cybersecurity. You can get plugins to download the text of webpages and build a nice search archive. Coupled with the free [NoteBook Navigator](https://community.obsidian.md/plugins/notebook-navigator), I have found this a game changer. ⭐️⭐️⭐️ Mac / Windows / Linux

Doing interviews? Wanting to transcribe. There's a tool for that, if you are on a Mac. The basic [MacWhisper](https://www.macwhisper.com/) is free, and uses local AI models to transcribe, so none of your data is shared in the cloud. It's pretty accurate too. ⭐️⭐️ Mac
