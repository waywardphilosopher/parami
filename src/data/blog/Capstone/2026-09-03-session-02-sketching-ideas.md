## Welcome back!

Welcome! Today we're going to get into groups to talk about our ideas and questions. It's going to be an open ended session where we can take time to think freely about the capstone — without any pressure — and to start coming up with ideas. 

I'll put you into small groups first of all, and give you ½ hour to talk about:

1. Your ideas — both the ones that seem quite wild, and the ones that seem safer
2. The problems that you anticipate in following up on these ideas
3. Any challenges that you anticipate in carrying out this project
4. Any questions you have about the  capstone course as a whole.

Please make notes as you talk, and we can come back to discuss in the main group. In each group, please appoint **one spokesperson** to feed back to the main group.

In the second half, I may set some writing tasks, or some thinking tasks, to get us started. But the main aim of today's session is to hear from you.
